Live data and poses

scene = Scene()
rover = add!(scene, load_stl("rover.stl"))
lidar = add!(scene, StreamingPointCloud(2_000_000; max_age = 100))   # newest 2M points
v = open_viewer(scene; block = false)

Threads.@spawn for msg in sensor_feed           # any thread: updates are locked
    set_pose!(rover, msg.position, msg.orientation)
    push_scan!(lidar, msg.points; pose = (msg.sensor_position, msg.orientation))
end
run!(v)

examples/live.jl simulates this with a ray-cast 16-beam LiDAR at 10 Hz. Use touch!(layer) after editing a layer's vertices in place.

SpatialRender.set_pose! — Function
set_pose!(layer, position, orientation=Quat(); scale=1) -> layer
set_pose!(layer, M::AbstractMatrix) -> layer

Place layer in the scene: its vertices are mapped by the pose into the scene frame. Thread-safe; takes effect on the next frame.

robot = add!(scene, load_stl("rover.stl"))
for (p, yaw) in telemetry
    set_pose!(robot, p, Quat(Vec3d(0, 0, 1), yaw))
end

SpatialRender.touch! — Function
touch!(layer) -> layer

Mark the layer's contents (vertices, indices, polylines) as changed after editing them in place; the renderer re-uploads it on the next frame.

SpatialRender.StreamingPointCloud — Type
StreamingPointCloud(capacity; name="live", point_size=2, color_mode=COLOR_AGE, max_age=50)

A point layer for live sensor feeds holding the most recent capacity points. Fill it with push_scan!. COLOR_AGE shades points by how many scans ago they arrived (newest bright, max_age scans and older dark).

source
SpatialRender.push_scan! — Function
push_scan!(layer, points; pose=nothing, intensity=nothing, classification=nothing) -> layer

Append one scan. points is a Vector{PointVertex} or a vector of 3-vectors in the sensor frame; pose (a 4×4 matrix, or a (position, Quat) tuple) maps them into the layer frame, so each scan lands where the vehicle was when it was taken. Thread-safe.

live = add!(scene, StreamingPointCloud(2_000_000))
@async for (pts, p, q) in lidar_feed
    push_scan!(live, pts; pose = (p, q))
end
open_viewer(scene)
