Pass block = false to get the Viewer back and drive it yourself (step!(viewer)), for example from a robot's update loop. Layers added to the scene while it is open are uploaded on the next frame.

Labels and measurements

Labels use a small stroke font drawn by the line shader, so no font files are needed. Measure mode in the viewer (R) calls measure! on the clicked points.

SpatialRender.Annotations — Type
Annotations(; name="annotations", width=2)

A layer of labels and measurement lines, drawn on top of the scene (never hidden by geometry). Add to it with annotate! and measure!; undo! removes the last addition.

Screenshots and headless use

render_offscreen and screenshot render without opening a window. On a machine without any display (a server or CI), GLFW falls back to its null platform and offscreen rendering still works where the OpenGL driver supports it. Set JULIA_GLFW_PLATFORM=null to say this is intended and silence GLFW's warnings.

SpatialRender.open_viewer — Function
open_viewer(scene; width=1280, height=800, title, block=true, camera=nothing, settings,
            vsync=true, player=nothing, visible=true) -> Viewer

Open a native window and render scene interactively (see HELP for controls; press H in the window). visible=false keeps the window hidden (automated tests, scripted captures). With block=false the function returns the Viewer immediately; call run!(viewer) or step!(viewer) to drive it, e.g. from a robot's own update loop.

SpatialRender.render_offscreen — Function
render_offscreen(scene; width=1024, height=768, camera=nothing, settings) -> Matrix{NTuple{3,UInt8}}

Render one frame into a hidden framebuffer and return it as an image (rows top to bottom). With camera=nothing the camera frames the scene from the south-west, 30° above the horizon. Useful for CI snapshots and batch reports.

SpatialRender.RenderSettings — Type
RenderSettings(; kwargs...)
  • background: clear color.
  • point_size_mode: :pixels (constant screen size) or :world (metres, shrinks with distance; world_point_size).
  • round_points: circular splats with sphere shading (false: squares).
  • lod_density: points drawn per pixel² of a chunk's screen footprint; Inf disables level of detail.
  • wireframe_color: overlay color for meshes with wireframe = true.
  • grid: draw a ground grid at z = 0.
  • edl, edl_strength, edl_radius: eye-dome lighting on points and meshes (screen-space depth shading; radius in pixels).
source
SpatialRender.pick! — Function
pick!(viewer, x, y; set_pivot=false) -> RayHit

Cast a ray through framebuffer pixel (x, y) against all meshes (BVH) and point clouds (chunk index, 4-pixel tolerance). Prints the hit in local and source coordinates and highlights picked points.
